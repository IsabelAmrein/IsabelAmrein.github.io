What it's about

This project collects what I learn in my master's in Data Science and generative AI. Each class becomes an entry: the core idea, an example of my own and, when possible, a small project to put it to the test.

How I work

  • In my own words. Classes and slides are my starting point, but every entry is written in my own words, with examples I build myself.
  • With small projects. If I can't build something small with an idea, I probably haven't understood it yet. Some live on their own page, like the recycling classifier.
  • With mistakes in plain sight. What goes wrong usually teaches more than what goes right.
