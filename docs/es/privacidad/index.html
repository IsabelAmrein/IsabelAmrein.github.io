Privacidad

Esta web no recoge datos personales ni te sigue. Aquí tienes, sin letra pequeña, qué ocurre exactamente.

Lo que guarda tu navegador

Solo dos preferencias, en tu propio dispositivo: el tema (claro u oscuro) y el idioma. No se envían a ningún servidor ni me llegan a mí.

Lo que no hay

No hay cookies de seguimiento, ni medición de visitas, ni anuncios, ni formularios, ni cuentas de usuario, ni recursos de terceros: las tipografías y el código se sirven desde esta misma web.

Dónde está alojada

La web se publica con GitHub Pages (GitHub, Inc.). Según su documentación, GitHub registra la dirección IP de quien visita una web de GitHub Pages, con fines de seguridad, aunque la persona no tenga cuenta. Yo no tengo acceso a esos registros. Más información en la documentación de GitHub Pages.

El nombre de dominio se gestiona en Cloudflare, solo como registro DNS: el tráfico de la web no pasa por Cloudflare.

Google Search Console

Uso Search Console, una herramienta gratuita de Google que me dice con qué palabras aparece esta web en las búsquedas. No instala nada en tu navegador ni añade código a esta web: se verificó con un registro en el nombre de dominio.

Enlaces a otros sitios

Si sigues un enlace a LinkedIn o a otra web, ese sitio aplica su propia política de privacidad.

Cambios y dudas

Si algún día añado algo que cambie lo anterior (un boletín por correo o una medición de visitas, por ejemplo), actualizaré esta página antes de activarlo.

Si tienes dudas, escríbeme por LinkedIn.
